# NSSN2 v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic event-driven recurrent NSSN2 network, freeze a v0 developmental-separation experiment, and provide a self-contained GitHub Pages microscope showing the same conceptual machine live.

**Architecture:** Python provides the scientific receipt: a latent-cause world, sparse stateful nodes, scalar routed events, local state-conditioned dynamics, and slow receiver-side route plasticity. A common world tape compares learning against a frozen control. Plain HTML/CSS/JavaScript provides a browser microscope with the same conceptual primitives but is not treated as evidence.

**Tech Stack:** Python 3.11/3.12, NumPy, pytest, plain HTML/CSS/JavaScript, GitHub Actions/Pages.

**Spec:** `docs/superpowers/specs/2026-09-17-nssn2-v0-design.md`

## Global Constraints

- No backpropagation or global training loss in v0.
- Travelling route events are scalar; high-dimensional access lives receiver-side.
- World labels are hidden from learning and used only for evaluation.
- Learning and frozen controls consume the exact same deterministic world tape.
- Keep negative results and shuffled-label sanity checks in the receipt.
- `index.html` is a microscope/demo, not scientific evidence.
- No framework/build step for the browser demo.
